# Quote Generator

A small page that serves a random quote from a collection of sixty, with a one click copy button.

## Features

- Sixty quotes from writers, thinkers and engineers
- Random order that never repeats the same quote twice in a row
- Copy the quote and author to the clipboard
- Press the space bar for another quote
- Fade animation on each change

## Running it

Open `index.html` in a browser. There is no build step and no dependencies to install.

## Files

```
index.html   markup
styles.css   styling
script.js    behaviour
```

## Tech

Plain HTML, CSS and JavaScript.
